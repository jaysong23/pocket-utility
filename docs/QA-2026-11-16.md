## 이번 수정

1. 품질 조정 시 기존 이미지 다운로드 결과를 폐기해 이전 품질의 파일을 새 설정 결과로 오인하지 않게 했다.
2. 이미지 추가/변환 중 페이지를 떠나면 후속 결과 저장을 중단하고 bitmap·canvas·object URL을 정리한다. 파일 목록 초기화 시 대기 중이던 파일 검사 결과가 다시 추가되지 않게 했다.
3. 손상된 뽀모도로 저장값은 해당 도구의 기본 시간(25분)으로 복구한다. 상태와 남은 시간이 모순된 저장값도 검증한다.
4. `/version.json`에 커밋 SHA와 빌드 시간을 기록해 실제 배포 버전을 확인할 수 있게 했다.

## 검증의 한계 및 기존 제약

- 사용 가능한 브라우저 연결이 없어 실제 브라우저의 파일 디코딩·다운로드 결과물, OS 알림 표시, PiP·전체화면, 모바일 배치·다크모드 시각 검사는 수행하지 못했다. 자동 테스트 통과를 실제 브라우저 전 기능 검증으로 해석하면 안 된다.
- 네이버·임의 서버 시각과 OG URL/이미지 URL 가져오기는 여전히 브라우저 CORS 허용 여부에 영향을 받는다. 서버 중계는 단축 URL 조회에만 적용한다.
- 단축 URL 도구는 HTTP 리다이렉트를 확인하며 로그인·보안 확인·JavaScript 전환을 실행하지 않는다. vo.la는 테스트용 리다이렉트 응답으로 검증했으며 실제 단축 링크는 제공되지 않았다.
- 실제 브라우저 알림은 권한과 OS 설정에 의존하며, 탭 종료·기기 절전 상태에서는 보장하지 않는다.
